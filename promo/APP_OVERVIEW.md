# Athenai Transit 概要

## 1. Athenai Transit とは

**目的地を入力しない、お散歩支援型の乗換案内 Web アプリ**です。

一般的な乗換案内が「目的地までの経路」や「時刻表」を提示するのに対し、Athenai Transit は「今、ここからどこへ行けるか」を提示します。行き先を「検索」するのではなく、表示された周辺の便を見て「選ぶ」。この体験の再定義が、偶然の発見と街歩きの楽しさを生み出します。

## 2. コンセプトと提供価値

目的地を決めずに街を歩き、近くのバス停や駅から次に出発する便にふらっと乗る。
朝から晩までフリー切符を握りしめ、行き当たりばったりの旅を楽しむ。
そんなお散歩を支援する乗換案内です。

### コアバリュー

- **偶然の発見**: 見慣れた場所にも必ずある「知らないバス停」や「未知のルート」。新しい街の顔を見つける楽しさ。
- **街歩きの自由**: いつでも近くの乗り物を探せる安心感がもたらす、迷子になる余裕と気ままな散歩。
- **面で捉える情報探索**: バス停ごとの情報を繰り返し調べる「点」の探索からの解放。周辺の発着便を俯瞰し、知らない場所でも好奇心と直感に任せた自由な乗り継ぎを実現。

### 機能的アプローチ

- **交通網の空間的な可視化**: 交通事業者ごとに分断された情報を横断的に統合。実在するのりばの情報をまとめて地図上に表示し、事業者の垣根を越えた直感的なのりば探索をサポート。
- **多様な表現による発着便の集約**: のりば毎の直近便を深掘りする表示から、周辺の複数のりばを集約した路線別の時系列表示や総合発着案内まで、発見を促す柔軟なインターフェース。
- **現在地と連動した動的案内**: のりばの探索時だけでなく、乗車中の体験も再構築。路線の全体像や終点までの残り時間を可視化し、見知らぬ土地での途中下車や乗り継ぎに向かう道中の不安を払拭。

## 3. おすすめのつかいかた

- **いつものお散歩**: いつものお散歩コースを外れて少し遠くへ。帰りの便がまだ動いている事実が、見慣れた街での小さな冒険へ連れ出す。
- **あてのない旅**: 目的地は決めない。フリー乗車券を握りしめ、直感のままにバスに飛び乗り、気になる景色で途中下車する。
- **ターミナル渡り鳥**: 接続性の高いターミナルをハブに、路線を次々乗り継いでバスネットワークの広がりを体感する。
- **地図を読む**: 複数の地図を切り替え、等高線や路地裏の形から街の地形と歴史を妄想するディープな使い方。
- **妄想バス旅**: 安全な自宅にいながらアプリ上で日時を変更、「見知らぬ土地の終バス」のスリルをソファで味わう。

## 4. デバイスと動作環境

- **モバイルファースト**: スマートフォンのモバイルブラウザでの利用を最優先とした画面設計。
- **PWA**: ホーム画面への追加によるブラウザ枠の排除と、地図を広く使える没入型の画面体験。Android(Chrome)/iPhone,iPad(Safari)対応。
- **デスクトップ**: 広い画面を活かした複数ペインレイアウト。情報比較や複数ペインの同時閲覧に最適なUIへの自動切り替え。

## 5. 機能の概要

- **地図**: 周辺ののりばをピン表示。現在地追従、複数タイルソース切替、選択路線ののりばレイヤー。
- **エッジマーカー**: 画面外ののりばの方向を端に表示し、パンに連動して更新。
- **発着情報 (StopTimes)**: 周辺の発着を複数 View で表示。発着時刻までの相対時間が小さい場合は相対時間、その他は絶対時刻を表示。
- **総合発着案内**: 周辺ののりばを集約し、事業者横断の「仮想統合発着案内」として直近の発着便を俯瞰。
- **時刻表 / 行程**: 広い時間範囲の一覧と、便ごとの識別情報。
- **日時セレクター**: 任意の日時で過去・未来を探索。
- **路線図とハイライト**: のりば選択に連動した、関連路線の視覚的なハイライト表示。
- **お気に入り (Portal/Anchor)**: Stop の登録とクイックアクセス。
- **情報レベル / 描画モード / 動作モード**: 情報量・描画負荷・表示範囲を調整。
- **多言語 / データソース選択 / 永続化 / キーボードショートカット / URL パラメータ制御**。

## 6. 画面・UI の構成

### 主要な構成要素

- **地図(MapView)**: 地図描画と各種コントロール（情報レベル切替、レイヤー/タイル切替、現在地、日時表示など）の統合面。「どこへ行けるか」を空間的に俯瞰する中心的なインターフェース。
- **発着案内(StopBrowser)**: 選択中ののりば・エリアの発着情報や時刻表を一覧する面。モバイルでは下部から引き上げ可能な BottomSheet、デスクトップでは1つの独立したペインとしてシームレスに機能。
- **ダイアログ**: 時刻表、行程、のりば検索、データソース選択、日時セレクターなど、必要に応じて素早くアクセスできる補助UI。

### 画面連携とレイアウト特性

- **レスポンシブ・デザイン**: 画面サイズに応じたレイアウトの自動最適化。地図を主表示とし探索の主導権を常に地図側に置く「モバイルUI」と、各パネルを横並びにする「デスクトップUI」。
- **情報レベル(InfoLevel)**: 画面上の情報解像度を自在にコントロール。
- **状態の即時連動**: 独立した画面遷移を排し、地図・発着案内・ダイアログ間で選択・フィルター・日時などの状態を完全共有。片方の操作結果をもう片方へ即時に反映。

## 7. 対応データ・カバレッジ

- **データ種別**: 静的な公共交通オープンデータ(GTFSなど)。
- **モード**: 鉄道・地下鉄・モノレール・新交通・路面電車・バス・コミュニティバス・フェリー (水上バス)、など。
- **エリア**: 首都圏を中心に、京都・名古屋・離島航路・地方フェリーから海外 (フライブルク/ヴェネツィア) まで多数のデータソースに対応。
- **データ選択**: ユーザーの目的や地域に応じた、利用データソースの自由な切り替えとオンデマンド読み込み。

### 導出データ (Insight)

Athenai Transit のデータ面の特徴として、配信データには元データをそのまま変換したものだけでなく、**独自に算出した派生指標(Insight)** が含まれる。

- **運行統計**: のりば単位の便数(運行頻度)・路線数・始発/終発時刻など。
- **地理指標**: 別路線の最寄りのりばまでの距離 (交通空白の度合い)、徒歩で渡れる近隣の駅、近隣圏の乗り継ぎ利便性など。

## 8. できないこと・制約 (Non-goals)

- **経路検索なし**: 目的地を指定した探索は行わない (これは制約ではなくコンセプト)。
- **リアルタイム遅延情報の非対応**: 遅延情報は「急がなきゃ」を誘発するため、あえて静的なダイヤのみに特化。
