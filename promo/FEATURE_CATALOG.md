# Athenai Transit 機能一覧

この文書は資料作成などで参照する為の中間文書である。中間データとして正確な情報を記載することを優先し、表現の洗練や構成の最適化は行わない。内容は随時更新される。

「あてのない乗換案内 (Athenai Transit)」が提供する機能を、機能カテゴリ別に分類した一覧です。
本書は主に App (WebApp) 側の機能を対象とする。データ生成 (Pipeline) の処理は原則として対象外だが、プロダクトの特徴である Insight データの生成のみ例外的に記載する。

## 1. マップ・探索機能 (Map & Navigation)

地図上にのりばや路線図を表示し、現在地周辺の交通網やのりばの位置関係を空間的・直感的に把握するための機能。

### 地図と現在地

- **周辺ののりば/駅を地図に表示**: 表示領域 (Bounding Box) 内ののりば/駅を、名称を含むマーカーで表示する。種別は配色で区別する。
- **ベースマップ**: 地理院地図 (標準地図) を既定とし、街歩きに適した詳細な地形・道を表示する。複数のタイルソースを切り替え可能 (色別標高図・淡色地図・航空写真・OSM 系など)。
- **現在地表示と追従**: Geolocation API で現在地を地図上に表示し、追従の ON/OFF を切り替えられる。

### 路線図とのりばレイヤー

- **路線図 (Route Shape)**: 路線図 (Polyline) を地図上に表示する。運行頻度の高い路線ほど太い線で描き、利用頻度の高さが視覚的に伝わる。
- **路線ハイライト**: のりばが選択されると、そののりばに関連する路線をハイライト表示する。
- **選択路線ののりば表示 (Route Stops Layer)**: のりばが選択されると、そののりばに関連する路線が経由する全のりばを専用レイヤーで表示する。路線図データが無い場合も走行区間を可視化できる。

### エッジマーカー (画面外インジケーター)

- 現在の表示領域の外側 (画面端から概ね 1〜2km) にあるのりば/駅を、名称と方向を含むマーカーとして画面の端に表示する。
- 「この方向へ歩けば乗り物がある」と直感できるようにする。
- 距離に応じて色分けし、情報レベルに応じて距離 (例: 240m) も併記する。
- 地図のパンに連動してリアルタイムに位置と表示を更新する。

### 地図操作・ナビゲーション

- **ズーム操作**: +/- ボタンやピンチ/スクロールでズームできる。
- **ランダムジャンプ**: 🎲 ボタンでランダムなプリセット場所へ移動し、知らない街の探索を促す。

### 地図上に表示するデータのフィルター

- 地図の表示にのみ作用するフィルター (他の画面の表示には影響しない)。
- **のりば種別フィルター**: バス/鉄道/地下鉄/その他の種別ごとに、地図上のマーカー表示を ON/OFF できる。
- **路線図の表示切替**: バス路線図と非バス路線図 (鉄道など) の表示を、それぞれ独立して ON/OFF できる。

### 距離の可視化

- **距離リング**: 地図中心からの同心円を距離帯ごとに色分けして表示し、「どのくらい先に乗り物があるか」を直感的に把握できる。
- **範囲サークル**: 総合発着案内の集約範囲など、対象としている範囲を地図上に重ねて示す。

## 2. のりば案内、発着案内 (Stop & Transit events)

のりばを中心とした発着情報などの、主要なデータを表現する機能。

### 近くののりばの基本情報

- のりば毎の情報を一覧表示。
- のりばの名称、現在地からの距離などのりばに関する基本情報を表示する。
    - のりば単位の統計・指標を表示する (元データそのものではなく、データから導出した指標)。
    - **運行統計**: 1 日あたりの便数 (運行頻度)、のりばを通る路線数、種別数、始発/終発時刻。サービスグループ (平日・土曜など) 単位。
    - **地理指標**: 別路線の最寄りのりばまでの距離 (交通空白の度合い)、徒歩で渡れる近隣の駅、300m 圏内の乗り継ぎ利便性 (路線数・運行密度・周辺のりば数)。

### のりばに関する発着便情報

- のりば毎の発着情報を、目的に応じて複数の View で表示する (並び順・グルーピング単位が異なる)。
    - **Stop view** (per-stop): 地図中心または現在地から最も近いのりばを優先表示。
    - **Route-Headsign view** (per-stop): 1 のりば内を Route+Headsign 単位でグルーピングし、同じ行先・系統の次発候補をまとめて比較できる。
    - **表示件数の制限**: 各路線/行き先 (系統) ごとに直近の最大 n 便のみを表示する。
- **時刻の UI 表現**:
    - まもなく出発する便(約15分(Viewにより異なる)): 現在時刻からの相対時間 (「あと〇分」) で強調表示。
    - それ以降の便: 絶対時刻 (例: `14:30`) で表示し、比較検討の材料とする。
- **行程内の現在位置**: 便に対する付加情報、全行程のうち、当該のりばが何番目かを示す (Stop view)
- **運行時間 / 終点までの所要時間**: 便に対する付加情報。行程全体の運行時間 (始発 → 終点) と、当該のりばから終点までの残り時間をバーで可視化する (Stop view)

### 総合発着案内

- 複数ののりばの発着情報をまとめた表示。
- 現在地周辺の複数ののりばを集約し、空港や大規模ターミナルの発着案内ボード (発車標) のように直近の発着便を一覧する。
- 現実には事業者ごとに分かれて存在しない統合発着案内を、事業者の垣根を越えて仮想的に構成する。ターミナルでなくてもどこでも周辺の発着便をまとめて把握できる。
- 集約する範囲 (半径) を切り替えられ、選択中の範囲を地図上にも示す。
- 交通機関の種別に応じて見せ方を変える (バス等は複数路線を 1 ボードに、鉄道等は路線・方向ごとに分割)。
- 出発便・到着便の表示をそれぞれ切り替えられる。

### 路線別発着案内

- 複数ののりばの発着情報をまとめた表示。
- 路線ごと・方向ごとに発着便を時系列で一覧する。
- 総合発着案内が複数路線をまとめて 1 ボードに畳むのに対し、こちらは路線単位で分けて見せる。路線でのフィルタにも対応。

### 発着情報のフィルター

- 発着情報の表示を絞り込むフィルター。地図の表示には影響しない。
- **種別 / 事業者**: StopBrowser 内で、種別 (バス/鉄道など) や事業者単位に絞り込む。
- **便の条件**: 始発のみ・乗車可能のみ・空ののりば省略 など、便の条件で絞り込む。

### のりば検索

- のりばを名前で検索し、結果を選択してそののりばへ移動できる。経路検索 (目的地検索) は提供しない。
- 表記ゆれを吸収してマッチする (大文字/小文字、カタカナ/ひらがな、ローマ字の発音記号など)。
- 🔍 ボタンで検索ダイアログを開く。候補の移動・確定はキーボードでも操作できる。

## 3. 時刻表・行程 (Timetable & TripInfo)

特定ののりばの一日分のダイヤ（時刻表）や、個別の便の運行ルート（行程）など、より詳細な運行データをドリルダウンして確認するための機能。

### 時刻表

- のりば毎に一日分の発時刻(もしくは着時刻)を一覧表示。
- 各便には系統を表示する。行き先は一覧でき、行き先で絞り込める (時刻表ダイアログ内のフィルタ)。
- 日時セレクターと連動し、指定した日付の時刻表を表示する。

### 行程

- 個々の便について、路線・行先・事業者・乗降可否などの情報を簡潔に表示する。発着情報・時刻表・TripInfo の各文脈で再利用される共通表現。

## 4. アプリケーション基盤・データ設定 (Core System & Data Management)

アプリの裏側で独自の統計・指標を算出するデータ基盤と、ユーザーが探索環境（データソース・日時・保存データ）を管理するための機能。

### Athenai Insights

Athenai Transit はデータ配信の前段で、元データから派生する **Insight (統計・指標) を独自に算出**する。これはプロダクトのデータ面の特徴のひとつ。

- **のりば単位の運行統計**: のりばごとの便数 (運行頻度)、路線数、種別数、始発/終発時刻。サービスグループ (平日・土曜など) 単位で算出する。
- **行路パターン統計**: 行路パターン単位の 1 日の便数や所要時間など (便を二重計上しない pattern-level の集計)。
- **横断的な地理指標**: 全データソースを横断して算出する、別路線の最寄りのりばまでの距離 (交通空白の度合い)、徒歩で渡れる近隣の駅、近隣圏 (例: 300m) の乗り継ぎ利便性 (路線数・運行密度・周辺のりば数) など。

### データソース選択

- 利用するデータ (事業者/路線群) を選択して読み込める。
- 鉄道・バス・フェリー・コミュニティバスから国内外まで多数のデータソースに対応。
- 一部はモバイル UI 右上の 📦 から選択。

### 日時セレクター

- 任意の日時を指定し、過去や未来の乗換案内を探索できる。
- ヘッダーの日時表示をタップでセレクターを開き、カスタム日時を設定する。
- カスタム日時モード中はヘッダーにインジケーターが表示され、現在時刻に戻すボタンを提供する。
- 日時変更に応じて、発着情報リスト・時刻表・のりばの統計が動的に更新される。

### お気に入り (Portal / Anchor)

- **Anchor**: 明示的に登録するお気に入りのりば。NearbyStop カードのトグルで追加/解除。
- **Portal**: 登録済み Anchor の一覧ドロップダウン。選択すると地図がそののりばへパンする。
- 軽量参照 (ID・名称・座標・路線種別など) で保持し、データ更新に強い設計。

### 永続化 (Web Storage)

- Web storage が使える環境では、ユーザー設定 (言語・テーマ・地図タイル・情報レベル 等)、のりば選択履歴、Anchor、有効化データソースをセッション間で永続化する。
- Web storage 不可環境でも crash せず起動し、起動時に 1 度だけ「永続化されない」旨を toast 通知する。永続化前提の操作 UI は機能発見性のため表示を維持する。

## 5. インタラクション・UX制御 (Interaction & UX Controls)

ユーザーの操作体験や、利用環境に応じたアプリケーションの振る舞いを制御・最適化する機能。

### 選択インタラクション

- のりば選択は「どののりばが選択されているか」という状態であり、複数の方法でトリガーされる。route だけを明示的に選択する UI は提供しない。視覚効果はこの選択状態から従属して決まり、地図・発着案内の両方へ即時反映される。
    - 選択をトリガーする方法 (例): 地図ののりばマーカー / 発着案内ののりば / 履歴 / Anchor・Portal / のりば検索の結果 / URL パラメータ `?stop=`。
    - のりばが選択されると: 選択したのりばのマーカーと、そののりばに関連する路線をハイライト表示する。
    - 選択を解除 (地図背景クリック等) すると: ハイライトを解除し、デフォルト表示に戻す。

### 情報レベル・描画モード・動作モード

- **情報レベル (InfoLevel)**: UI の情報量を 4 段階で制御 (`simple` / `normal` / `detailed` / `verbose`)。上位レベルは下位を内包する閾値方式。
- **動作モード (PerfMode)**: 取得するデータの範囲・件数を `lite` / `normal` / `full` の 3 段階で切り替え、端末性能や探索範囲に応じて性能と網羅性のバランスを選ぶ。
- **描画モード (RenderMode)**: のりばマーカーの描画方式を `auto` / `standard` (標準=リッチ) / `lightweight` (軽量=多数マーカー向け) で切り替える。

### レスポンシブレイアウト

- **モバイル UI**: 地図を主表示とし、下部に引き上げ可能な StopTimes の BottomSheet を重ねる。探索の主導権は常に地図側にある。
- **デスクトップ UI**: Map・StopTimes・補助パネルを横並び/分割で表示する MultiPane レイアウト。各ペインは選択・フィルター・日時の状態を共有し、操作が即時反映される。
- 画面サイズに応じて自動で切り替わる (モバイルファースト)。

### 多言語表示と言語切替

- 表示言語の切り替えに対応 (翻訳名の表示を含む)。

### キーボードショートカット

- 主要操作にキーボードショートカットを提供する (ヘルプは `?` キー)。

### PWA (ホーム画面へのインストール)

- ホーム画面に追加するとブラウザ枠が消え、地図を広く表示できる。
- Android (Chrome) / iPhone・iPad (Safari) でインストール可能。

### URL パラメータによる制御

- URL パラメータで初期状態や動作を制御でき、デモ URL の共有に利用できる。
    - 例: `?sources=` (データソース指定) / `?lat=` `?lng=` `?zm=` (初期表示位置) / `?time=` (初期日時) / `?stop=` (初期選択 stop) / `?tileIdx=` (タイル) / `?lang=` (言語)。

## 提供しない機能 (Non-goals)

- 経路検索 (目的地を指定した探索)
- リアルタイム遅延情報の反映
